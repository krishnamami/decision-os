# Decision OS

A governed, explainable, human-in-the-loop decision platform.
Domain-agnostic engine. Domain packs for each vertical.

## Stack
- Backend: Python 3.11 + FastAPI
- Data models: Pydantic v2
- Database: Supabase (Postgres)
- Cache: Redis
- Frontend: Next.js + Tailwind

## Hard rules
- No decision without owner
- No action without policy
- No context without lineage
- No agent without permissions
- No execution without trace
